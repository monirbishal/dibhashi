Overview

Dibhashi is an AI‑powered platform that transforms English videos into natural-sounding Bengali dubs with emotion and timing alignment preserved. The modular pipeline: Whisper → Custom EN→BN NMT → VITS TTS → FFmpeg merge.

System Architecture

The pipeline consists of:

  • 🟦 Input video / URL → extract first 30 sec with yt‑dlp + ffmpeg
  • 🟩 Speech Recognition via Whisper‑small to generate time‑stamped English text
  • 🟨 Translation using a custom fine‑tuned NMT model (EN → BN)
  • 🟪 Text‑to‑Speech synthesis via VITS with voice‑cloning
  • 🟫 Audio post‑processing: noise reduction, volume normalization, silence padding
  • 🔊 Video merge: synchronizing processed WAV onto original video using ffmpeg’s -shortest flag

EN → BN NMT Model Details

Model: monirbishal/en‑bn‑nmt

  • Tatoeba English–Bengali (10,000+ pairs)
  • BanglaNMT dataset (3,518 pairs)
  • Custom-curated ~500 entries from social media and spoken content

Evaluation BLEU: ~15.03; Loss: ~1.914 (original training from Hugging Face) Final fine-tuned BLEU: ~33.15 (from latest run).

Setup & Local Usage

Clone and install:

git clone https://github.com/monirbishal/dibhashi.git  
cd dibhashi  
pip install -r requirements.txt

Then run using the local script as documented in INSTALL.md. (Note: full Colab demo not yet available.)

Python API & CLI

Dibhashi backend is built with Flask; core modules include transcript, translate, synthesize, process, and merge. A simple CLI script invokes each stage in order—perfect for automation.
